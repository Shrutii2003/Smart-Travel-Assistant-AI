**About the Project**
Smart Travel Assistant is an AI-powered application designed to help users plan trips by providing destination recommendations, hotel suggestions, local food information, and travel guidance.

**Features**
Destination-based travel planning
Hotel and local food recommendations
Travel route information
AI-powered trip suggestions
User-friendly interface

**Technologies Used**
Python
Streamlit
Large Language Model (LLM) API
DuckDuckGo search/images (if used in your implementation)

**Installation**
Clone or download this repository.
Install the required dependencies:
pip install -r requirements.txt
Configure your API key securely using environment variables.

**Run the application:**
streamlit run app.py

**Future Enhancements**
Real-time flight information
User login and trip history
Improved destination recommendations
